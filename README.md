# ConfNav
ConfNav is an Android conference agenda and navigation app for managing conference sessions, viewing schedules by day, finding venues on a map, and navigating to session locations.

It is designed for conference attendees, organizers, and volunteers who want a lightweight tool to keep track of agenda items, speakers, locations, and venue navigation in one place.

Easily build your agenda at https://urzahil.github.io/ConfNav-Web/ and load the JSON into the app.

## Features
- Agenda view with day-based filtering
- Next-event overview for quick planning
- Session details including title, speaker, time, description, and venue
- Interactive map with venue pins and location-based session grouping
- Quick directions to event locations
- Add, edit, and manage conference sessions
- Import and export session data as JSON
